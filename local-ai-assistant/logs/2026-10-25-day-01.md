## Goal

Build Buer, a local AI assistant on Windows 11, using the RX 6650 XT 8 GB for AI while keeping the RX 9060 XT 16 GB available for gaming.

## Hardware & setup

- Ryzen 7 5800X, 48 GB DDR4, ASRock X470 Master SLI.
- Windows 11 23H2.
- LM Studio with llama.cpp Vulkan 2.64.0.
- Model: Qwen3-VL-8B-Instruct Q4_K_M (~6.19 GB).
- Context length: 4096 tokens.
- RX 9060 XT deselected in LM Studio; RX 6650 XT is the intended inference GPU.

The model download was unusually slow despite fast internet, reaching around 2 Mbps, but eventually completed.

## Building Buer

Created a basic Python desktop assistant connected to LM Studio through its local API.

**Project files**
- `main.py` — Tkinter chat interface and AI communication.
- `voice.py` — Piper text-to-speech.
- `notes_manager.py` — Local Markdown note management.
- `buer_config.txt` — Assistant instructions.
- `notes/` and `voices/` — Local notes and voice model files.

**Working features**
- Chat with the local AI through a GUI.
- Maintain conversation history during the current session.
- Create, list and read notes using commands.
- Speak responses using Piper TTS.
- Toggle voice output and adjust its volume.

Speech runs in a background thread to avoid blocking the interface unnecessarily. It currently starts after the complete written response appears, so reducing that delay remains a future improvement.

## Python environment & launcher

- Created `.venv` using Python 3.12.10.
- Installed `requests` and `piper-tts`.
- Verified package imports and compiled the Python files without syntax errors.
- Created `Start Buer.bat` for one-click launching.

**End-to-end test:** Buer launched successfully, sent a message to LM Studio and displayed the AI response.

LM Studio must still be running with the model loaded and its local server enabled.
